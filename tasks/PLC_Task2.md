# Практическая работа 2
Вторая практическая работа для освоения программирования мехатронной системы с дачтиком цвета (сортировка зеленых и голубых деталей)
# Задание

## Цель практической работы:
Разработать программу для мехатронной станции сортировки заготовок по цвету на язке FBD в среде TIA Portal

## Ход работы
- Открыть файл шаблона проекта в программе TIA Portal 
- Собрать элементы станции в проекте Factory IO согласно заданию
- Добавить новую функцию FC1 на языке программирования FBD
- Написать в коде функции FC1 алгоритм согласно заданию
- Добавить вызов функции FC1 в блоке OB1
- Протестировать и отладить программу, используя Factory IO
- Продемонстрировать верное функционирование программы преподвателю

## Алгоритм работы станции

1. Emitter выдает заготовку типа blue raw material или green raw material по нажатию на кнопку "старт" на шкафе

2. Заготовка транспортируется в зону определения материала (цвета). Зона находится под датчиком vision sensor

3. Датчик vision sensor настроен на распознавание голубых заготовок (заготовка голубая = 1, заготовка зеленая = 0). 

4. Голубые заготовки транспортируются на ближний скат (скат 1) и удаляются с помощью remover 1

5. Зеленые заготовки транспортируются в конец конвейера (скат 2) и удаляются с помощью remover 2.

Только после перемещения заготовки на скат (любой) может быть выдана следующая заготовка в начале конвейера.

Задача считается выполненной, если 5 случайных заготовок были верно транспортированы с помощью системы.

Вы можете настраивать время появления и удаления деталей по собственному усмотрению.
