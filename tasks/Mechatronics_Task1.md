# Практическая работа 1 по Мехатронике

Первая практическая работа по блоку "Мехатроника". Вы должны собрать и запрограммировать базовые станции и представить отчет по работе.

## Цель практической работы:
Освоить сборку и программирование мехатронных устройств на примере учебных станций конвейера, стекового накопителя и манипулятора.

## Что делать

1. Выполнить сборку каждой из 3 станций: конвейер, стековый накопитель, манипулятор, в соответствии с указаниями преподавателя;
2. Сделать фото собранных станций для добавления в отчет;
3. В среде FluidSim запрограммировать каждую из 3 станций в соответствии с в соответствии с указаниями преподавателя;
4. Сделать скриншоты готовых программ для добавления в отчет.

## Отчет

Заголовок подраздела: Сборка и наладка учебных мехатронных станций
Содержание отчета (список для каждой станции, всего 3 станции): 
- название станции
- описание и состав станции (кратко, воспользоваться учебником, расположенным по ссылке: [учебник](https://github.com/zoratrix/mechatronics/blob/main/resources/MecLab_%D1%83%D1%87%D0%B5%D0%B1%D0%BD%D0%B8%D0%BA.pdf) 
- фотография собранной станции
- кратко описание алгоритма работы станции
- скриншот программы
